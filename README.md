# Shortcut

Halaman shortcut pribadi untuk membuka situs favorit lewat kartu warna-warni. Cukup satu file HTML, tanpa instalasi dan tanpa proses build.

## Fitur
- Tambah, edit, hapus, dan urungkan kartu
- Atur huruf, nama, link, dan warna kartu
- Urutkan kartu dengan seret (HP dan desktop)
- Pencarian cepat
- Sapaan otomatis atau teks sendiri
- Efek suara dengan pengatur volume
- Animasi halus, mengikuti mode "kurangi gerakan"
- Mode gelap otomatis
- Responsif
- Data tersimpan di browser (`localStorage`)

## Cara Pakai
Buka `index.html` di browser.

## Pintasan Keyboard
| Tombol | Fungsi |
|---|---|
| `/` | Cari |
| `N` | Tambah kartu |
| `E` | Mode edit |
| `D` | Mode hapus |
| `S` | Mode urutkan |
| `T` | Ubah teks sapaan |
| `P` | Pengaturan |
| `M` | Suara nyala/mati |
| `1`–`9` | Buka kartu |
| `Ctrl+Z` | Urungkan hapus |
| `Esc` | Keluar mode |

## Teknologi
HTML, CSS, dan JavaScript murni. Font Bricolage Grotesque dari Google Fonts.

## Catatan
Data hanya tersimpan di browser yang dipakai dan tidak tersinkron antar perangkat. Menghapus data browser akan menghapus kartu.
